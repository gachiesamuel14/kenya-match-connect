# Kenya Match Connect

Location-based dating app for people in Kenya.

## Features (MVP)
- Mock profiles with Kenyan counties (Nairobi, Mombasa, Kisumu, Kiambu)
- Swipe-like interface (Like / Pass)
- Simulated distance and location permission request
- Matches tracking

## Next Steps for Full App
1. User auth (Firebase Auth or Supabase)
2. Real GPS matching with geolocation + distance calc (Haversine)
3. Photo uploads (Cloudinary or Supabase Storage)
4. Real-time chat (Socket.io or Supabase Realtime)
5. Filters: county, age, tribe, interests, religion
6. Safety/report system
7. M-Pesa payments for premium (Daraja API)
8. Modes: Student / Professional / Church
